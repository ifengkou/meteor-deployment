# ICP Diag 客户交付指南

适用：License SDK 0.7.1、Issuer 0.4.0；首次客户安装沿用宿主授权目录与独立 `license-init`，不引入新的部署体系。核查日期：2026-10-26。

**本次客户目标已确认：Linux x86_64／AMD64，四个交付镜像统一为 `linux/amd64`。** 最终验收在原生 Linux AMD64 上执行，包含实际 DAT 解密、解析与航空业务；ARM64 演示仅作历史参考。

**当前结论：具备进入正式构建和交付验收的条件，尚不能宣布开发验收与正式发版全部完成。** 已有 ARM64 演示和自动测试证明部分链路可用；新正式信任、冻结提交、原生 AMD64 验收及真实业务仍需在本次发行上闭环。详情见[收口核查](readiness.md)。

| 顺序 | 文档 | 执行方 | 完成标志 |
| --- | --- | --- | --- |
| 0 | [收口核查与发布门槛](readiness.md) | 研发、实施、验收负责人 | 本次范围、平台、四仓基线和待验项明确 |
| 1 | [构建与交付包](01-build.md) | 我方制作人员 | 固定提交、正式配置、客户模式镜像、统一包核验通过 |

| 3 | [授权签发](03-license-issue.md) | 我方签发人员 | 用匹配发行公钥的私钥签出客户许可，保存记录和摘要 |

时间顺序为：**我方冻结并构建 → 独立环境验收与组包 → 客户校验并导入镜像 → 准备私有配置和模型 → 初始化安装 → 启动服务 → 取得申请 → 我方签发 → 客户导入 → 最终业务验收**。镜像导入与商业许可导入是两个步骤。

## 交付边界

通用包由 `local-stack.py export` 生成，包含四个镜像、部署资产、本文档、manifest 和 SHA256SUMS。完整 Embedding、Chat 模型服务、业务配置、客户资料和凭据按专用清单另行交付或由客户提供。

客户包无需源码、Git、JDK、Node、宿主 SDK 或签发工具。Issuer、私钥、口令和签发记录只保留在我方。本文相邻阶段链接随包提供；指向其他工程的链接仅供完整研发工作区查证，不是客户操作前提。

既有环境升级从[更新手册](../updates.md)、[SDK 升级](../license-sdk-upgrade.md)和[备份恢复](../backup-restore.md)执行，跳过首次 `init` 和 `license-init`。历史 [0.7.1 演示](../sdk071-container-deployment.md)、旧[签发演练](../license-issuer-hands-on.md)及 0.6.0 HTML 不作为本次正式交付操作入口。
