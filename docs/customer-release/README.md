# ICP Diag 客户交付指南

适用：Linux x86_64／AMD64，License SDK 0.7.1、Issuer 0.4.0。首次安装使用宿主授权目录与独立 license-init，已有安装按更新流程保留配置、数据和授权资料。本机 Docker Desktop 使用 [local-release/](../local-release/README.md)。

## 按阶段执行

| 顺序 | 文档 | 执行方 | 完成标志 |
| --- | --- | --- | --- |
| 0 | [发布检查清单](readiness.md) | 研发、实施、验收负责人 | 目标环境、发布输入和验收范围明确 |
| 1 | [build：镜像与统一交付包](01-build.md) | 我方制作人员 | 发布提交、正式配置、客户模式镜像和完整包核验通过 |
| 2 | [deploy：首次部署与更新](02-deploy.md) | 客户运维／我方实施 | 配置、目录、授权安装、迁移和服务健康检查通过 |
| 3 | [授权签发](03-license-issue.md) | 我方签发人员 | 用匹配发行公钥的私钥签出客户许可 |
| 4 | [授权导入与验收](04-license-import.md) | 客户管理员／我方实施 | Metor／AI 各自 ACTIVE，业务与运维验收完成 |
| 并行准备 | [模型、业务资料与凭据](business-materials.md) | 我方实施与客户业务方 | 权重、Chat、场景、规则、知识资料和账号可用 |

首次安装顺序：冻结版本并构建 → 统一组包并核验 → 客户导入镜像 → 准备配置与目录 → 初始化授权安装 → 数据库迁移与启动 → 签发许可 → 导入许可 → 验收。镜像导入与商业许可导入分别执行。

## 交付内容

统一交付包由 local-stack.py export 生成，包含四镜像、完整 Embedding、部署资产、五份客户使用指南、manifest、SHA256SUMS，以及获准复用的三项数据库密码和 JWT 密钥。交付 tar.gz 及其 .sha256，按私有客户制品保管。Chat 服务、业务配置和客户资料按清单准备。

客户运行预制镜像，宿主不需要源码、Git、JDK、Node、授权 SDK 或签发工具。本目录为我方制作与实施指引；客户包只包含 customer-docs/ 的五份自包含使用指南。

## 已有安装更新

按 [deploy 第 7 节](02-deploy.md#7-已有环境更新)执行，保留完整授权资料和运行配置。SDK 版本变化按[兼容要求](../license-sdk-upgrade.md)核对，备份和恢复按[运维流程](../backup-restore.md)执行。
