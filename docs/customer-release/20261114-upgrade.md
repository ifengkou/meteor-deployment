# 1103 → 1114 amd64 升级补充

先使用当前 1103 部署的脚本、Compose 和原 `docker.env` 完成备份并校验 `SHA256SUMS`，再切换到 1114 的部署入口和镜像。

1114 首次将航空诊断配置从宿主机只读挂载到 Metor。重建 Metor 前，按 **1114 发行包内** `deployment/docs/business-config.md` 的「航空诊断文件配置」从 `metor-service:release-20261114-1-amd64` 提取完整配置。宿主机目录默认是 `/data/metor/ai631/conf`，以原 `docker.env` 中的 `METOR_RULES_CONFIG_HOST_PATH` 为准。

如果已手工创建空目录，可保留该目录，把本次发行镜像对应的 `fault_scene.json`、`readArg.json`、`event_seq.json` 和 `event_pair.json` 直接复制到目录根。目录权限为 0755，文件为 0644。已有现场配置时先备份并核对缺项，保留客户定制内容。
