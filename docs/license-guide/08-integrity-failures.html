完整性与失败处理

清单保护、CAS、原子提交和备份边界

几个看起来相似的“摘要”和“密钥”，用途不同。把它们混用，最容易造成操作错误。

四类密钥 / 信任材料

材料持有者保护对象
我方 Ed25519 私钥issuer 签发环境商业许可与恢复文件的签发权
固定 Ed25519 公钥产品构建元数据允许验证哪些我方签名，运行参数不能替换
客户 identity/service.key安装授权目录，本地受限读clock / recovery challenge 的 HMAC，派生 CONTROL key
原用户 JWT 与会话凭据已有账号认证系统用户登录权限；授权 403 不等于登录失效

这些摘要不能互换

字段对应字节用途
商业 fileDigest当前 active.license.json 整个文件商业导入 expectedFileDigest 的 CAS 基准
payloadDigest / licenseDigest商业许可载荷载荷追踪，不能代替商业整文件 CAS
恢复 apply 响应 fileDigest本次上传的恢复文件恢复文件追踪；不得回填商业 CAS
issuer artifact_digest签发输出完整文件我方输出核对和同 ID 重试
api_routes_sha256入包路由 JSON 原始字节启动验证包内清单完整性
state_identity / target_idclock 原始记录摘要 / 恢复目标绑定本次异常，不能当商业绑定码

清空配置为什么不能关闭关键入口？

我方构建原始规则 JSON 的 SHA256 固定到包内元数据
→
启动验证资源唯一、摘要匹配、非空且规则有效
→
不可变内存策略运行中不重读，不接受外部覆盖
→
固定方法 guard与 HTTP 层共用策略状态与 SDK

启动时文件被改

POLICY_INVALID；拒绝业务，保留精确登录/健康/授权修复 API，原鉴权继续执行。

运行中修改文件

内存规则不变；下次启动检测并拒绝。恢复正确发行包后重启，不做实时文件监控。

此处依赖我方发行包和构建元数据。主动改程序并同步替换预期摘要属于改包攻击，不在“误复制、常规超范围使用”的防护承诺内。没有 sign-policy 命令或额外策略签发记录。

商业导入的 CAS：防覆盖，不是另一层签名

伪代码，不直接执行
管理员 A、B 都读到当前文件摘要 D1
A 提交 new-A，expectedFileDigest=D1 → 校验后发布 D2
B 提交 new-B，expectedFileDigest=D1 → 当前已是 D2，返回 409
B 必须刷新核对，再明确决定是否提交

没有当前文件时，成功 GET 返回 null，导入传 NONE
状态 GET 失败时，不得擅自把“未知”当“无文件”传 NONE

为什么 HTTP 202 不能当成功？

校验 / 加锁尚未发布可安全拒绝
→
临时文件写入与同步准备完整字节
→
原子替换读取者看到完整旧文件或新文件
→
目录持久性确认确认后才可报告已提交
结果含义操作
提交前失败尚未确认发布新状态保留原资料，按错误排查
APPLIED持久提交已确认刷新实际商业状态；恢复成功仍可能过期
ALREADY_APPLIED当前记录的同恢复 ID 已完成只确认，不再降低时间基准
OUTCOME_UNKNOWN / 202可能已替换，但持久性未确认恢复用同文件重试；商业导入先刷新核对文件摘要
409 TARGET_CHANGED恢复目标不再适用重新取得当前申请；新目标须另签新编号

一次商业文件原子发布不是两服务内存同步事务，也不是跨多个文件的全局事务。恢复的内存刷新只有在本服务持久提交确认后才执行。

备份要带走什么？

整栈维护窗口按既有备份流程停止写入
→
license-state.tar.gz安装 UUID、service.key、商业许可、两端 clock/挑战
→
私有备份与校验保留摘要和数值权限，排除锁/临时文件
→
同宿主空目标恢复先恢复原安装资料，再启动；不是重新 license-init

授权备份含本地安装密钥，属于私有资料，不放进普通镜像发行包。恢复拒绝不同安装或非空目标；换机/重装重新签发，不新增迁机、撤销或旧授权处置。恢复旧备份也不能承诺抵御整机快照攻击。

四种常见误判

误判正确理解
健康检查通过 = 许可有效健康与许可独立；受控接口可返回 403 而进程健康
无绑定 = 不需要身份/时钟只免机器绑定，Runtime 仍需身份、密钥及时间保护
恢复窗口 = 商业有效期窗口只限制首次应用恢复；商业期限不变
ControlProof = 我方签发权只证明已有安装级维护凭据与本次请求；不能替代我方 Ed25519 恢复签名
对照代码 / 操作文档商业 CAS、原子发布及摘要包内清单加载与维护例外安装级 ControlProof 与用途派生授权归档校验与恢复边界可重复执行的隔离备份验证说明
