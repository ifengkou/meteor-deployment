阅读时固定这五个边界

  1. SDK 与 issuer 独立维护；私钥和签发工具不随客户产品交付。
  2. 默认可共用一个商业许可文件，但 Metor/AI 独立校验、独立状态、独立恢复。
  3. 回拨容差是 24 小时，商业生效/到期和恢复窗口没有这一天宽限。
  4. 客户镜像已预装授权运行依赖；授权判断不依赖外网。业务模型服务的连接由业务配置另行决定。
  5. 本手册对照当前源码；Phase 7 页面待人工验收，Phase 8 客户目标 Linux / 最终镜像尚未验收，不等于正式发布完成。
